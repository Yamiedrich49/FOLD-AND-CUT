# FOLD & CUT — 問題品質監査（2026-11-06）

## 今回のユーザーフィードバック

- 展開後の選択肢に、切り口ではない斜線（隣接するポリゴンの内部境界）が見えてしまう。
- 折った部分とは無関係な箇所だけを切り、折らずに切った場合と完成形が同じになる問題は、簡単すぎて学習上の価値が低い。
- 初期難易度全般は適切なので、安易に難度を上げすぎないこと。

## 内部境界（偽の折り目）の原因と修正

複数の塗りつぶしポリゴンから構成される正答形に、一括でSVG strokeを設定していた。隣り合うポリゴンの共有辺までstrokeが描かれ、切り口や折り目のように見えてしまう。

`index.html` の選択肢・選択肢拡大・正解チップに `paint-order: stroke fill` を適用し、塗りつぶしが内部の共有辺を上書きするよう変更。最終展開後の紙にも同じ設定を適用。実際の外周・穴の縁は残す。

レベル30の旧問題は左辺の切り込みと、不要な右下の対角線（内部境界）が混在する典型例。

## 「折っても意味がない」問題の検査

折り方・切り方から生成された最終シルエット `final` を、**元の正方形を折らずに `cutPath` だけで切った場合のシルエット**と比較する。

320×320の紙を5単位ピッチの点格子でサンプリングし、偶奇規則（even-odd）のポリゴン塗りつぶし判定で両者の差を測る。

- 差がゼロで、紙から除去された実面積も十分ある問題 → 折ることが完成形に何ら寄与していないとみなす。
- 差がゼロでない問題 → 折ったことによる差はある。ただしその差が面白さ・難易度として十分かは別途検証が必要。

初期100問の監査では、下記20問を該当と判定した。

`2, 7, 11, 15, 19, 23, 30, 37, 40, 44, 47, 51, 60, 65, 72, 74, 86, 88, 91, 95`

## 修正方法（現時点の暫定的な品質改善）

元の500問データを消したり再生成したりせず、`index.html` にて対象20レベルのみ既存の「折った効果が最終形に現れる」出題の回転・反転バリエーションに差し替える。現在の対応は `MEANINGFUL_EARLY_VARIANTS` を参照。

- 操作、切り抜き、展開アニメ、選択肢、正答、比較用図形を**同じ幾何変換**で変更して整合性を保つ。
- 章と問題番号、既存の進捗保存キー、全500問の構成を保持。
- 既存の良問を再利用するため、一部の数学的な構造は後の問題で繰り返される（方向は異なる）。これは**恒久対応ではなく暫定策**とし、将来的には独立した良問に置き換える。
- 問題に意味があることと良問であることは違う。7歳の実機試遊を最終判断とする。

## 次回の品質向上

1. 原データ500問すべてに対して同じ「無関係なカット」を検査し、序盤以外も棚卸しする。
2. 問題生成ツール自体に「紙を折らずに切った場合とのシルエット差が一定以上」の必須条件を組み込む。
3. 暫定の回転・反転バリエーションを、独立した切り方の新規問題に順次置換する（単なる重複を避ける）。
4. 四択の図形を実機で見て、内部境界の消失と本当の切り口の視認性を確認する。
5. 実機で初期100問の難易度変化が急でないか確認する。

公開版のブラウザ動作はこの環境では未確認。GitHubコードの静的チェック・ファイルの存在確認と、実機の表示確認は分けて管理する。
